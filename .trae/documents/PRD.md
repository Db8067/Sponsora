# Product Requirements Document (PRD)

## 1. Project Overview
**Name**: Nexora (or to be decided)
**Description**: The premier platform for hosting, sponsoring, and participating in tech events, hackathons, and conferences.
**Target Audience**: Students, professionals, corporate teams, NGOs.

## 2. Core Features
- **Public Homepage**: Event discovery, trending events, search, categories.
- **Participant Dashboard**: Registrations, bookmarks, public profile, certificates.
- **Organizer Dashboard**: Event management, analytics, chat with admin.
- **Sponsor Dashboard**: Event listings, chat with admin, subscriptions.
- **Admin Portal**: Approve organizers, manage events, moderate chats.

## 3. Scope & MVP Sprint
- **Day 1**: Setup apps, Clerk, Supabase, Cloudinary, Design System.
- **Day 2**: Public pages (Homepage, Event Listing, Event Detail).
- **Day 3-10**: Auth roles, Dashboards, Realtime Chat, Payments (Razorpay), Deployment.
